2. Media File Specifications & Guidelines Asset Standards

🖼️ Photography & Imagery

  • Format: WebP or high-res JPG / PNG
  • Hero Banners: 1920x1080px (16:9), under 400KB
  • Card Thumbnails: 1200x800px (3:2)
  • Headshots: 800x800px (1:1), transparent or solid dark background

📐 Logos & Brand Icons

  • Format: Vector SVG (Preferred) or Transparent PNG (300 DPI)
  • Variations: Dark-mode light color version & full-color version
  • Compliance: ISO, SOC2, Agency badges in crisp vector format

📑 Documents & PDFs

  • Format: Compressed PDF (under 5MB per document)
  • Content: Whitepapers, Case Studies, Media Kits, Investor Factsheets
  • Metadata: Embedded title, author, and description tags

📥 Recommended Delivery Workflow for Management / Content Team:

  1. Google Drive / Shared Folder: Organize assets into folders by page name (e.g., /01_About_Us/, /02_Products/, /03_Team_Headshots/).
  2. Shared Copy Document: Provide text copy in a shared Google Doc or Notion page corresponding to each table section above.
  3. Frontend Integration: The frontend team will immediately inject the approved text and wire up high-res assets into the live React components.
